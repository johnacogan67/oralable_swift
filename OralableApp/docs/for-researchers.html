For Researchers

Temple photoplethysmography, structured exports, and methods work on motion artifact.

McGill / RI-MUHC methods work

We work with a researcher at McGill University / RI-MUHC on methods to reduce motion artifact and improve interpretability of temple PPG during sleep. That work informs filtering choices and protocol design. It is not a substitute for independent peer review, and it is not a signed institutional trial.

Technical capabilities

Real-time raw CSV export

50 Hz-aligned Oralable lanes (PPG, accelerometry, derived channels) for offline analysis and institutional tooling.

Charlton framework signal processing

Pulse waveform analytics and band-limited PPG processing consistent with the Charlton pulse-wave literature, supporting HOI / temporalis load interpretation.

Overnight oxygen-burden context

Session exports can include overnight SpO₂ context next to temple load. This is research context, not an apnea index or a medical hypoxic-burden claim.

Overnight state hypnogram

Patient app + Clinical PDF show a hypnogram-first overnight view (device-inferred quiet / tonic / phasic / rescue / recovery). Primary UX for long nights; full CSV/PDF for offline analysis.
